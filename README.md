# Анализ банковских транзакций

Приложение для анализа банковских транзакций с веб-страницами, сервисами и отчетами.

## Функциональности

### Веб-страницы
- **Главная страница**: Обзор карт, топ транзакций, курсы валют, цены акций
- **Страница событий**: Анализ расходов и поступлений по категориям

### Сервисы
- **Выгодные категории кешбэка**: Анализ наиболее прибыльных категорий
- **Инвесткопилка**: Расчет суммы для накоплений через округление трат
- **Простой поиск**: Поиск транзакций по описанию или категории
- **Поиск по телефонным номерам**: Поиск транзакций с мобильными номерами
- **Поиск переводов физлицам**: Поиск переводов физическим лицам

### Отчеты
- **Траты по категории**: Анализ трат по категориям за 3 месяца
- **Траты по дням недели**: Средние траты по дням недели
- **Траты в рабочие/выходные дни**: Сравнение трат по типам дней
